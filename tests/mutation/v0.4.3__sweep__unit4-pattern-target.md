## Caveat

A kill proves the suite noticed *this* change, not that it tests the right thing. **A clean sweep is evidence about the mutations tried, not proof of suite completeness.**

M9 also showed that the existing JSON test, `test_match_first_updates_only_the_first_field`, could not tell the first field from the last: it counted versions. It now compares the whole file with the exact expected text. On its own, it kills M9 (`v0.4.3__json-match-first.redgreen.*`).
